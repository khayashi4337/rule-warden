# rule-warden

AI（Claude）の長期記憶・ルールファイルを、汚染から守りながら管理するツール。

## これは何か

`C:\Users\user\.claude` 配下のルール（CLAUDE.md 系列）を 1 条単位で棚卸しし、
汚染スコア付きの一覧・隔離・復元・追加審査（PR）を行う管理システム。
詳細は `docs/adr/0001-requirements-and-architecture.md` を参照。

## なぜあるのか

AI が自分の権限を広げる方向へルールを自己追加し、自浄作用が働かないレベルまで
記憶が汚染される事態が起きた。いったん全ルールを退避し、必要なものだけを
人間の確認付きで復元して、汚染度を下げることを目的とする。
最終的にはルールを適正化した状態で AI に再び自由を渡す。
